# 1. (Practice Question) Explore and describe the problem

* Text resources: Chapter 3, Appendix B

Prompt: Evaluate a problem description according to JHEBP5

```
You are an expert in evidence-based practice in healthcare. Please evaluate this problem description according to JHEBP 5th Edition guidelines for a problem description. What elements of the problem description are present and well-described? (What is the local problem? Why is this problem important and relevant? What would happen if it was not addressed? What is the current practice in the EBP team's setting? What data from the EBP team's setting indicates there is a problem?) What elements of the problem description are missing or are not described in sufficient detail to be helpful in completing the steps of the JHEBP 5th Edition process? Please provide rationale for your statements and quote passages from the text that support your assertions. Please provide the full text for the quotations page numbers for the quotations. Please suggest ways to improve the problem description.
```

```

```

```
You are an expert in evidence-based practice in healthcare. Based on the problem description provided, suggest several intervention evidence-based practice questions using interventions you suggest based on the problem description.
In addition, please list a justification why you feel the intervention is worth considering for each question you suggest.

```

```
You are an expert in evidence-based practice in healthcare. Please evaluate this EBP question. First, please classify the EBP question as a broad EBP question or a practice EBP question. Please provide a rationale for each inclusion/exclusion determination. Please generate a final list of all titles that should be included with ID numbers needed for article retrieval.
```
